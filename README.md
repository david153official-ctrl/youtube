# TubeGenius - 헐리우드 스타일 유튜브 대본 생성기

유튜브 알고리즘과 헐리우드 시나리오 작법을 결합한 AI 기반 콘텐츠 제작 도구입니다.

## ✨ 주요 기능

### 🎬 헐리우드 시나리오 기법 적용
검증된 4가지 스토리텔링 구조를 자동으로 분석하고 적용합니다:

#### 1. **픽티안 커브 (Fichtean Curve)** - 썰/사이다 채널용
- **타겟 감정**: 분노/복수/억울함
- **구조**: 발단 → 위기1 → 위기2 → 절정(사이다) → 결말
- **스타일**: '존 윅' 스타일의 복수극
- **목표**: 고구마를 먹이다가 마지막에 강력한 사이다 터뜨리기

#### 2. **영웅의 여정 (Hero's Journey)** - 성공담/국뽕 채널용
- **타겟 감정**: 감동/성장/희망
- **구조**: 결핍 → 계기 → 시련 → 성취 → 변화
- **스타일**: 휴먼 다큐멘터리
- **목표**: 웅장함과 감동을 주는 성장 서사

#### 3. **인 미디어스 레스 (In Medias Res)** - 미스터리/공포 채널용
- **타겟 감정**: 공포/미스터리/긴장
- **구조**: 훅(충격) → 회상 → 전개 → 진실 → 여운
- **스타일**: 넷플릭스 스릴러 예고편
- **목표**: 결말을 먼저 보여주어 호기심 극대화

#### 4. **행오버 스타일 (Mystery Comedy)** - 엽기/유머 채널용
- **타겟 감정**: 황당/유머/혼란
- **구조**: 혼란 → 되감기 → 스노우볼 → 반전
- **스타일**: 시트콤
- **목표**: 황당한 상황을 강조하여 웃음 유발

### 📋 마스터 시스템 프롬프트 기반 작성
모든 대본은 다음 원칙을 따릅니다:
- **페르소나**: 헐리우드 최고 몸값의 시나리오 각색가
- **문체**: 인터넷 커뮤니티 특유의 구어체 (음슴체/해요체)
- **편집**: 불필요한 서론 삭제, 바로 본론 진입
- **과장**: 팩트 유지 + 감정 묘사 극적 과장 (MSG 첨가)
- **연출**: BGM/효과음 타이밍 가이드 포함

### 🎯 3단계 워크플로우

1. **원문 정밀 분석**: 핵심 감정과 소재의 잠재력 파악
2. **콘텐츠 진단서**: AI가 최적의 헐리우드 기법 매칭 및 주제 리브랜딩
3. **완성된 대본**: 선택한 기법에 맞춘 구조화된 시나리오

### 📦 제공 기능

- 핵심 감정 자동 분석 (분노/감동/공포/황당함)
- 소재 잠재력 평가
- 바이럴 가능성 높은 주제 3가지 추천 (각기 다른 기법 적용)
- 각 주제별 썸네일/제목 추천 3가지 (자극형/호기심형/공감형)
- 기법별 맞춤 대본 구조
- 오프닝 훅 (0~10초 강렬한 시작)
- BGM/효과음 연출 가이드 포함
- 타이밍 명시 (00:00-00:30 형식)

## 🚀 시작하기

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key

3. Run the app:
   ```bash
   npm run dev
   ```

## 🛠️ 기술 스택

- **Frontend**: React + TypeScript + Vite
- **Styling**: TailwindCSS
- **AI**: Google Gemini 2.5 Flash (분석) + Gemini 3 Pro Preview (대본 생성)
- **Icons**: Lucide React

## 📖 사용 방법

1. 기존 대본이나 아이디어를 입력하세요
2. AI가 자동으로 감정을 분석하고 최적의 헐리우드 기법을 선택합니다
3. 3가지 추천 주제 중 하나를 선택하세요
4. 헐리우드 스타일로 구조화된 완성된 대본을 받으세요!
